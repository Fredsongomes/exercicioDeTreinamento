# Exercícios de Lógica de Programação e POO em Java

Repositório com os exercícios que resolvi durante meus estudos de **Lógica de Programação** e **Programação Orientada a Objetos (POO)** em Java.

Os exercícios estão organizados por etapa de aprendizado, do básico (entrada e saída de dados) até conceitos de POO como herança e interfaces. Cada pasta tem um `README.md` próprio explicando o que o exercício faz, os conteúdos utilizados e como ele funciona.

## Tecnologias

- Java 26
- Maven

## Estrutura do projeto

```
src/main/java/com/
├── logica/   → 35 exercícios de Lógica de Programação (ex01 a ex35)
└── poo/      → 18 exercícios de Programação Orientada a Objetos (ex01 a ex018)
```

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Fredsongomes/exercicioDeTreinamento.git
   ```
2. Abra o projeto em uma IDE com suporte a Maven (por exemplo, IntelliJ IDEA).
3. Execute a classe que contém o método `main` do exercício desejado. Nos exercícios de POO, é a classe de teste (`...Teste` / `Teste...`).
