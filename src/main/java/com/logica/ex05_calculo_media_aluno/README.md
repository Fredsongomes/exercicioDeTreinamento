# Operadores Aritméticos: Média Aritmética de Notas

> **Módulo:** Lógica de Programação · **Exercício 05** · Pasta `ex05_calculo_media_aluno`

## O que é o exercício

Exercício de cálculo de média aritmética com precedência de operadores.

## O que ele faz

Lê o nome do aluno e três notas e exibe a média aritmética.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis dos tipos `String` e `double`
- Operadores aritméticos
- Parênteses para controlar a precedência
- Saída de dados com `System.out.println`

## Como funciona

1. Lê o nome e as três notas.
2. Soma as notas entre parênteses e divide por 3.
3. Exibe a média.

## Principais conceitos praticados

- Precedência de operadores
- Cálculo de média aritmética
