# Estrutura Condicional Encadeada: Verificação de Múltiplas Condições

> **Módulo:** Lógica de Programação · **Exercício 23** · Pasta `ex23_condicoes_multiplas`

## O que é o exercício

Exercício de encadeamento de condições com operadores relacionais diferentes.

## O que ele faz

Lê um número e informa se ele é maior que 80, menor que 25, igual a 40 ou se não se encaixa em nenhuma dessas condições.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura condicional encadeada (`if / else if / else`)
- Operadores relacionais `>`, `<` e `==`

## Como funciona

1. Lê um número.
2. Testa as condições em ordem: `> 80`, `< 25` e `== 40`.
3. Exibe a mensagem da primeira condição verdadeira, ou uma mensagem padrão.

## Principais conceitos praticados

- Ordem de avaliação em condições encadeadas
- Uso do operador de igualdade `==`
