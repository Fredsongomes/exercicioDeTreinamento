# Operadores Aritméticos: Cálculo de Prestações

> **Módulo:** Lógica de Programação · **Exercício 10** · Pasta `ex10_calculo_prestacoes`

## O que é o exercício

Exercício simples de divisão de um valor em parcelas.

## O que ele faz

Lê o valor de uma compra e exibe o valor de cada uma das 5 prestações.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis do tipo `double`
- Operador de divisão
- Saída de dados com `System.out.println`

## Como funciona

1. Lê o valor da compra.
2. Divide o valor por 5.
3. Exibe o valor da prestação.

## Principais conceitos praticados

- Divisão com números decimais
- Fluxo entrada → processamento → saída
