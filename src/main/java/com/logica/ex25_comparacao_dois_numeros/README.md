# Estruturas Condicionais Aninhadas: Comparação de Dois Números

> **Módulo:** Lógica de Programação · **Exercício 25** · Pasta `ex25_comparacao_dois_numeros`

## O que é o exercício

Exercício com uma condição dentro de outra.

## O que ele faz

Lê dois números e informa se são iguais. Se forem diferentes, também informa qual é o maior.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estruturas condicionais aninhadas (`if/else` dentro de `else`)
- Operadores relacionais `==` e `>`

## Como funciona

1. Lê dois números.
2. Se forem iguais, informa isso.
3. Caso contrário, informa que são diferentes e, em uma segunda decisão, exibe o maior.

## Principais conceitos praticados

- Aninhamento de estruturas condicionais
