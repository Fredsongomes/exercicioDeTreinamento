# Estrutura Condicional Composta (if/else): Maior entre Dois Números

> **Módulo:** Lógica de Programação · **Exercício 14** · Pasta `ex14_maior_entre_dois_numeros`

## O que é o exercício

Exercício de decisão entre dois caminhos.

## O que ele faz

Lê dois números inteiros e exibe o maior deles.

## Conteúdos utilizados

- Entrada de dados com `Scanner` (`nextInt()`)
- Estrutura condicional composta (`if/else`)
- Operador relacional `>`
- Saída de dados

## Como funciona

1. Lê dois números inteiros.
2. Se o primeiro for maior que o segundo, exibe o primeiro.
3. Caso contrário, exibe o segundo.

## Principais conceitos praticados

- Decisão com dois caminhos (`if/else`)
- Comparação entre valores
