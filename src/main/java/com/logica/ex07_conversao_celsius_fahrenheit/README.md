# Operadores Aritméticos: Conversão de Celsius para Fahrenheit

> **Módulo:** Lógica de Programação · **Exercício 07** · Pasta `ex07_conversao_celsius_fahrenheit`

## O que é o exercício

Exercício de aplicação de fórmula de conversão de temperatura.

## O que ele faz

Lê uma temperatura em graus Celsius e exibe o valor convertido para Fahrenheit.

## Conteúdos utilizados

- Entrada de dados com `Scanner` (`nextInt()`)
- Variáveis do tipo `int`
- Operadores aritméticos com precedência
- Saída de dados com `System.out.println`

## Como funciona

1. Lê a temperatura em Celsius.
2. Aplica a fórmula `(C * 9 / 5) + 32`.
3. Exibe a temperatura em Fahrenheit.

## Principais conceitos praticados

- Aplicação de fórmula matemática
- Precedência de operadores
- Aritmética com números inteiros
