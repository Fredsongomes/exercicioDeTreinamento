# Estrutura de Seleção (switch-case): Número por Extenso

> **Módulo:** Lógica de Programação · **Exercício 26** · Pasta `ex26_numero_por_extenso`

## O que é o exercício

Primeiro exercício com a estrutura `switch`.

## O que ele faz

Lê um número de 1 a 5 e exibe o número por extenso. Para outros valores, exibe "número inválido".

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura de seleção `switch` com `case`, `break` e `default`

## Como funciona

1. Lê um número inteiro.
2. O `switch` seleciona o `case` correspondente e exibe o nome do número.
3. O `default` trata valores fora de 1 a 5.

## Principais conceitos praticados

- Seleção múltipla por valor exato
- Uso de `break` para encerrar cada caso
- Tratamento de valor inválido com `default`
