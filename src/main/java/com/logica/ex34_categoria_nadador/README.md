# Estrutura Condicional Encadeada com Intervalos: Categoria de Nadador

> **Módulo:** Lógica de Programação · **Exercício 34** · Pasta `ex34_categoria_nadador`

## O que é o exercício

Exercício de classificação por faixas etárias.

## O que ele faz

Lê a idade de um nadador e informa a categoria: Infantil A, Infantil B, Juvenil A, Juvenil B ou Sênior. Idades fora dessas faixas geram uma mensagem própria.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura condicional encadeada
- Operador lógico `&&`
- Operadores relacionais `>=` e `<=`

## Como funciona

1. Lê a idade.
2. Testa as faixas 5–7, 8–10, 11–13, 14–17 e 18–25.
3. Exibe a categoria da faixa correspondente ou "Idade fora da faixa etária!".

## Principais conceitos praticados

- Verificação de intervalos com `&&`
- Classificação em várias faixas
