# Operadores Aritméticos: Cálculo de Consumo Médio

> **Módulo:** Lógica de Programação · **Exercício 03** · Pasta `ex03_calculo_consumo_medio`

## O que é o exercício

Exercício de aplicação de fórmula simples com tipos inteiros.

## O que ele faz

Lê a distância total percorrida e o total de combustível gasto e exibe o consumo médio do veículo.

## Conteúdos utilizados

- Entrada de dados com `Scanner` (`nextInt()`)
- Variáveis dos tipos `int` e `double`
- Conversão explícita de tipo (casting) com `(double)`
- Operador de divisão (`/`)
- Saída de dados com `System.out.println`

## Como funciona

1. Lê a distância e o combustível como números inteiros.
2. Converte a distância para `double` e divide pelo combustível, preservando as casas decimais.
3. Exibe o consumo médio.

## Principais conceitos praticados

- Aplicação de fórmula matemática
- Tipos inteiros e de ponto flutuante
- Casting para evitar a divisão inteira, que descartaria a parte decimal do resultado
