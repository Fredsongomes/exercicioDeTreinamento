# Estrutura de Repetição (for) e Contador: Números em um Intervalo

> **Módulo:** Lógica de Programação · **Exercício 17** · Pasta `ex17_contagem_numeros_intervalo`

## O que é o exercício

Primeiro exercício com laço de repetição.

## O que ele faz

Lê 80 números e, ao final, exibe quantos estão no intervalo de 10 a 150.

## Conteúdos utilizados

- Estrutura de repetição `for`
- Constante `final` para o total de repetições
- Variável contadora
- Operador de incremento (`++`)
- Estrutura condicional `if`
- Operador lógico `&&`

## Como funciona

1. Define `TOTAL_NUMEROS = 80`.
2. Repete a leitura de um número 80 vezes com `for`.
3. A cada número dentro de `[10, 150]`, incrementa o contador.
4. Após o laço, exibe o total contado.

## Principais conceitos praticados

- Repetição com número fixo de iterações
- Padrão contador
- Condição dentro de laço
