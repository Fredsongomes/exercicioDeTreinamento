# Constantes e Cálculo Percentual: Custo do Carro ao Consumidor

> **Módulo:** Lógica de Programação · **Exercício 12** · Pasta `ex12_calculo_custo_carro`

## O que é o exercício

Exercício de cálculo com percentuais sucessivos definidos em constantes.

## O que ele faz

Lê o custo de fábrica de um carro e exibe o custo final ao consumidor, com 45% de impostos e 28% do distribuidor.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Constantes declaradas com `final`
- Variáveis do tipo `double`
- Operadores aritméticos
- Cálculo percentual em cascata

## Como funciona

1. Define as constantes `PERCENTUAL_IMPOSTOS` e `PERCENTUAL_DISTRIBUIDOR`.
2. Lê o custo de fábrica.
3. Aplica o percentual de impostos sobre o custo de fábrica.
4. Aplica o percentual do distribuidor sobre o valor já com impostos.
5. Exibe o custo ao consumidor.

## Principais conceitos praticados

- Constantes para valores fixos do problema
- Cálculos percentuais sucessivos
