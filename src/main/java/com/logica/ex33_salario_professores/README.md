# Estrutura Condicional Encadeada e Constantes: Salário de Professores

> **Módulo:** Lógica de Programação · **Exercício 33** · Pasta `ex33_salario_professores`

## O que é o exercício

Exercício de cálculo com valores diferentes conforme uma categoria.

## O que ele faz

Lê o nome, o nível (1, 2 ou 3) e a quantidade de aulas de um professor e calcula o salário conforme o valor da hora-aula de cada nível (R$ 12, R$ 17 ou R$ 25).

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Constantes `final`
- Estrutura condicional encadeada (`if / else if / else`)
- Operador de igualdade `==`
- Operadores aritméticos

## Como funciona

1. Lê nome, nível e quantidade de aulas.
2. Escolhe o valor da hora-aula de acordo com o nível.
3. Multiplica a quantidade de aulas pelo valor da hora-aula.
4. Para nível inválido, exibe "Valores Inválidos" e o salário permanece 0.
5. Exibe o salário.

## Principais conceitos praticados

- Regras de negócio com constantes
- Tratamento de opção inválida
