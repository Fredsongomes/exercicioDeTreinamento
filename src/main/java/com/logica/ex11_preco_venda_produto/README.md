# Cálculo Percentual: Preço de Venda de Produto

> **Módulo:** Lógica de Programação · **Exercício 11** · Pasta `ex11_preco_venda_produto`

## O que é o exercício

Exercício de cálculo de preço de venda a partir do custo e de uma margem de acréscimo.

## O que ele faz

Lê o custo de um produto e o percentual de acréscimo desejado e exibe o preço de venda.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis do tipo `double`
- Operadores aritméticos
- Cálculo percentual
- Saída de dados com `System.out.println`

## Como funciona

1. Lê o custo do produto.
2. Lê o percentual de acréscimo (por exemplo, `30` para 30%).
3. Calcula `custo + (custo × percentual / 100)`.
4. Exibe o preço de venda.

## Principais conceitos praticados

- Aplicação de porcentagem sobre um valor
- Fluxo entrada → processamento → saída
