# Estrutura de Seleção (switch-case): Mês do Ano

> **Módulo:** Lógica de Programação · **Exercício 29** · Pasta `ex29_mes_do_ano`

## O que é o exercício

Exercício de prática do `switch` com muitos casos.

## O que ele faz

Lê um número de 1 a 12 e exibe o nome do mês correspondente, ou "Mês inválido".

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura de seleção `switch` com 12 casos, `break` e `default`

## Como funciona

1. Lê o número do mês.
2. O `switch` exibe o nome do mês correspondente.
3. O `default` trata valores inválidos.

## Principais conceitos praticados

- Seleção múltipla
- Escrita compacta de `case` em uma única linha
