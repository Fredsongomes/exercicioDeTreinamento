# Operadores Lógicos: Verificação de Número em Intervalo

> **Módulo:** Lógica de Programação · **Exercício 15** · Pasta `ex15_numero_no_intervalo`

## O que é o exercício

Exercício que combina duas condições com operador lógico.

## O que ele faz

Lê um número e informa se ele está no intervalo entre 100 e 200, inclusive.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura condicional `if/else`
- Operadores relacionais `>=` e `<=`
- Operador lógico E (`&&`)

## Como funciona

1. Lê um número inteiro.
2. Verifica se o número é `>= 100` **e** `<= 200`.
3. Exibe se o número está ou não no intervalo.

## Principais conceitos praticados

- Combinação de condições com `&&`
- Verificação de intervalos fechados
