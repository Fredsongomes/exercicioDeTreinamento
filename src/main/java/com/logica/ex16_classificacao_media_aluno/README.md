# Estrutura Condicional Encadeada (if/else if/else): Situação do Aluno

> **Módulo:** Lógica de Programação · **Exercício 16** · Pasta `ex16_classificacao_media_aluno`

## O que é o exercício

Evolução do exercício de média, agora com classificação do resultado.

## O que ele faz

Lê o nome e três notas de um aluno, calcula a média e informa se o aluno está aprovado, em recuperação ou reprovado.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Operadores aritméticos (média)
- Estrutura condicional encadeada (`if / else if / else`)
- Operadores relacionais `>=` e `<=`

## Como funciona

1. Lê o nome e as três notas.
2. Calcula a média aritmética.
3. Média `>= 7`: **Aprovado**.
4. Média `<= 5`: **Reprovado**.
5. Qualquer outro caso: **Recuperação**.

## Principais conceitos praticados

- Classificação em mais de duas faixas
- Encadeamento de condições
