# Variáveis e Atribuição: Troca de Valores com Variável Auxiliar

> **Módulo:** Lógica de Programação · **Exercício 06** · Pasta `ex06_troca_de_valores`

## O que é o exercício

Exercício clássico de manipulação de variáveis.

## O que ele faz

Lê dois valores, A e B, troca o conteúdo entre eles e exibe os valores trocados.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Declaração de múltiplas variáveis `double` na mesma linha
- Operador de atribuição (`=`)
- Variável auxiliar
- Saída com `System.out.print` e `System.out.println`
- Comentário de linha (`//`)

## Como funciona

1. Lê os valores de A e B.
2. Guarda A em `aux`, copia B para A e depois `aux` para B.
3. Exibe os novos valores de A e B.

## Principais conceitos praticados

- Atribuição de valores entre variáveis
- Uso de variável auxiliar para não perder dados
