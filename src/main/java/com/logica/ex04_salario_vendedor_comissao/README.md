# Entrada de Dados e Cálculo Percentual: Salário com Comissão

> **Módulo:** Lógica de Programação · **Exercício 04** · Pasta `ex04_salario_vendedor_comissao`

## O que é o exercício

Exercício que combina leitura de texto e números com cálculo de porcentagem.

## O que ele faz

Lê o nome do vendedor, o salário fixo e o total de vendas no mês, calcula a comissão de 15% e exibe o salário final.

## Conteúdos utilizados

- Entrada de dados com `Scanner` (`nextLine()`, `nextDouble()`, `nextInt()`)
- Variáveis dos tipos `String`, `double` e `int`
- Operadores aritméticos (`*` e `+`)
- Cálculo percentual
- Saída de dados com `System.out.println`

## Como funciona

1. Lê o nome, o salário fixo e o total de vendas.
2. Calcula a comissão multiplicando o total de vendas por `0.15`.
3. Soma a comissão ao salário fixo.
4. Exibe nome, salário fixo e salário final.

## Principais conceitos praticados

- Leitura de texto e de números
- Cálculo de porcentagem
- Uso de diferentes tipos de dados
