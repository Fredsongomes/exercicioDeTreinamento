# Estrutura de Repetição (for) e Comparação de Strings: Homens e Mulheres

> **Módulo:** Lógica de Programação · **Exercício 19** · Pasta `ex19_contagem_homens_e_mulheres`

## O que é o exercício

Exercício de repetição com leitura e comparação de texto.

## O que ele faz

Lê nome e sexo de 56 pessoas, informa o sexo de cada uma e exibe o total de homens e de mulheres.

## Conteúdos utilizados

- Estrutura de repetição `for`
- Constante `final`
- Leitura de texto com `nextLine()`
- Comparação de `String` com `equalsIgnoreCase()`
- Estrutura condicional `if/else`
- Contadores

## Como funciona

1. Repete 56 vezes a leitura de nome e sexo.
2. Se o sexo for "M" (maiúsculo ou minúsculo), conta como homem.
3. Caso contrário, conta como mulher.
4. Ao final, exibe os totais.

## Principais conceitos praticados

- Comparação de strings ignorando maiúsculas/minúsculas
- Padrão contador
