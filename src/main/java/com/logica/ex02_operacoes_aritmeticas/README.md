# Operadores Aritméticos: As Quatro Operações

> **Módulo:** Lógica de Programação · **Exercício 02** · Pasta `ex02_operacoes_aritmeticas`

## O que é o exercício

Exercício de prática dos quatro operadores aritméticos básicos.

## O que ele faz

Lê dois números e exibe o resultado da soma, subtração, multiplicação e divisão entre eles.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis do tipo `double`
- Operadores aritméticos `+`, `-`, `*` e `/`
- Saída de dados com `System.out.println`
- Concatenação de `String`

## Como funciona

1. Lê dois números com `nextDouble()`.
2. Calcula soma, subtração, multiplicação e divisão, cada uma em sua própria variável.
3. Exibe os quatro resultados.

## Principais conceitos praticados

- Uso dos operadores aritméticos
- Armazenamento de resultados intermediários em variáveis
