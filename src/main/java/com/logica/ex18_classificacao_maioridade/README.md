# Estrutura de Repetição (for) com Múltiplos Contadores: Maioridade

> **Módulo:** Lógica de Programação · **Exercício 18** · Pasta `ex18_classificacao_maioridade`

## O que é o exercício

Exercício de repetição com classificação e contagem por categoria.

## O que ele faz

Lê a idade de 10 pessoas, informa se cada uma é maior ou menor de idade e, ao final, exibe o total de cada grupo.

## Conteúdos utilizados

- Estrutura de repetição `for`
- Constante `final`
- Estrutura condicional `if/else`
- Dois contadores independentes
- Operador de incremento (`++`)

## Como funciona

1. Repete 10 vezes a leitura de uma idade.
2. Idade `>= 18`: exibe "Maior de idade" e incrementa o contador de maiores.
3. Caso contrário: exibe "Menor de idade" e incrementa o contador de menores.
4. Ao final, exibe os dois totais.

## Principais conceitos praticados

- Contagem por categoria
- Decisão dentro de laço
