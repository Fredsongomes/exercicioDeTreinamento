# Operadores Aritméticos: Conversão de Dólar para Real

> **Módulo:** Lógica de Programação · **Exercício 08** · Pasta `ex08_conversao_dolar_real`

## O que é o exercício

Exercício de conversão de moeda com cotação fixa.

## O que ele faz

Lê um valor em dólares e exibe o valor equivalente em reais, usando a cotação de 5,12.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis do tipo `double`
- Operador de multiplicação
- Concatenação de `String`
- Saída de dados com `System.out.println`

## Como funciona

1. Lê o valor em dólares.
2. Multiplica o valor pela cotação `5.12`.
3. Exibe o valor original e o convertido.

## Principais conceitos praticados

- Conversão de valores
- Formatação de saída por concatenação
