# Entrada de Dados e Operadores Aritméticos: Soma de Dois Números

> **Módulo:** Lógica de Programação · **Exercício 01** · Pasta `ex01_soma_dois_numeros`

## O que é o exercício

Primeiro exercício do módulo de lógica. Introduz a leitura de dados pelo teclado e o uso de um operador aritmético.

## O que ele faz

Lê dois números informados pelo usuário e exibe a soma entre eles.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Variáveis do tipo `double`
- Operador aritmético de adição (`+`)
- Saída de dados com `System.out.println`
- Concatenação de `String`
- Fechamento do `Scanner` com `close()`

## Como funciona

1. Cria um `Scanner` para ler o teclado.
2. Solicita e lê o primeiro e o segundo número com `nextDouble()`.
3. Soma os dois valores e guarda o resultado em uma variável.
4. Exibe o resultado e fecha o `Scanner`.

## Principais conceitos praticados

- Fluxo básico entrada → processamento → saída
- Declaração e atribuição de variáveis
- Operações aritméticas simples
