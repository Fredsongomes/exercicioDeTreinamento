# Repetição com Quantidade Variável e Condicionais: Positivo, Negativo ou Zero

> **Módulo:** Lógica de Programação · **Exercício 24** · Pasta `ex24_positivo_negativo_zero`

## O que é o exercício

Exercício de classificação de vários números dentro de um laço.

## O que ele faz

Lê a quantidade N de números e, para cada número informado, diz se é positivo, negativo ou zero.

## Conteúdos utilizados

- Estrutura de repetição `for` com limite informado pelo usuário
- Estrutura condicional encadeada (`if / else if / else`)
- Operadores relacionais `>` e `<`

## Como funciona

1. Lê N.
2. Repete N vezes a leitura de um número.
3. Classifica cada número como Positivo, Negativo ou Zero.

## Principais conceitos praticados

- Laço com tamanho definido em tempo de execução
- Classificação dentro de laço
