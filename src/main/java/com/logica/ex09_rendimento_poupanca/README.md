# Constantes e Operadores Aritméticos: Rendimento da Poupança

> **Módulo:** Lógica de Programação · **Exercício 09** · Pasta `ex09_rendimento_poupanca`

## O que é o exercício

Exercício que introduz o uso de constantes em cálculos financeiros.

## O que ele faz

Lê o valor depositado e exibe o rendimento de um mês e o valor final, com taxa fixa de 0,07%.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Constante declarada com `final`
- Variáveis do tipo `double`
- Operadores aritméticos
- Comentário de linha (`//`)
- Saída com `System.out.print` e `System.out.println`

## Como funciona

1. Define a constante `TAXA_JUROS = 0.0007`.
2. Lê o valor depositado.
3. Calcula o rendimento e soma ao depósito.
4. Exibe o rendimento e o valor final.

## Principais conceitos praticados

- Uso de constantes (`final`)
- Convenção de nomes em maiúsculas para constantes
- Cálculo de juros simples de um período
