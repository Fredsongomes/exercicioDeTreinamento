# Estrutura Condicional Simples (if): Número Maior que Dez

> **Módulo:** Lógica de Programação · **Exercício 13** · Pasta `ex13_numero_maior_que_dez`

## O que é o exercício

Primeiro exercício com estrutura condicional.

## O que ele faz

Lê um número e, se ele for maior que 10, exibe uma mensagem informando isso.

## Conteúdos utilizados

- Entrada de dados com `Scanner`
- Estrutura condicional simples (`if`)
- Operador relacional `>`
- Saída de dados

## Como funciona

1. Lê um número.
2. Testa se o número é maior que 10.
3. Exibe a mensagem apenas se a condição for verdadeira. Caso contrário, nada é exibido.

## Principais conceitos praticados

- Tomada de decisão com `if`
- Expressões booleanas com operadores relacionais
