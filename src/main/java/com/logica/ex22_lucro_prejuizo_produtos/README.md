# Estrutura de Repetição (for), Acumuladores e Médias: Lucro ou Prejuízo

> **Módulo:** Lógica de Programação · **Exercício 22** · Pasta `ex22_lucro_prejuizo_produtos`

## O que é o exercício

Exercício que combina repetição, decisão e cálculo de médias.

## O que ele faz

Lê o preço de custo e de venda de 40 produtos, informa se cada um dá lucro, prejuízo ou empate e exibe a média dos preços de custo e de venda.

## Conteúdos utilizados

- Estrutura de repetição `for`
- Constante `final`
- Estrutura condicional encadeada (`if / else if / else`)
- Acumuladores (`+=`)
- Cálculo de média

## Como funciona

1. Repete 40 vezes a leitura dos preços de custo e de venda.
2. Compara os preços e exibe Lucro, Prejuízo ou Empate.
3. Acumula os preços de custo e de venda.
4. Ao final, divide as somas por 40 e exibe as médias.

## Principais conceitos praticados

- Padrão acumulador
- Cálculo de média após o laço
- Classificação em três casos
